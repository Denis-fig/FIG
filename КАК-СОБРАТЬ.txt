MiniFig — десктоп-приложение (Mac / Windows)
=============================================

ГЛАВНОЕ: пользователь (дизайнер) НИЧЕГО не собирает.
Он получает ОДИН файл-установщик и запускает его. Всё.
Сборку (где нужен Node) делаете вы ОДИН раз — и раздаёте коллегам
один готовый файл.

Что получает пользователь (одна кнопка)
---------------------------------------
MAC:     файл MiniFig-1.0.0-arm64.dmg  → двойной клик → перетащить MiniFig в «Программы».
WINDOWS: файл MiniFig-1.0.0-x64.exe    → двойной клик → ставится сам, сразу запускается.

Больше ничего от пользователя не требуется (Node и т.п. — не нужны).

Как получить этот файл-установщик — 2 способа
---------------------------------------------

СПОСОБ 1 — собрать у себя (нужен Node.js один раз):
  MAC:     поставьте Node.js с nodejs.org (LTS) → двойной клик по
           «Собрать-MiniFig-Mac.command» → в папке dist появится .dmg.
  WINDOWS: поставьте Node.js с nodejs.org (LTS) → двойной клик по
           «Собрать-MiniFig-Windows.bat» → в папке dist появится .exe.

СПОСОБ 2 — собрать в облаке GitHub (ни Node, ни сборки у вас):
  1. Создайте репозиторий на github.com и загрузите туда эту папку
     (файл .github/workflows/build.yml уже внутри).
  2. Вкладка Actions → «Сборка MiniFig» → Run workflow.
  3. Через ~5 минут скачайте готовые установщики из артефактов сборки
     (Mac .dmg и Windows .exe). Раздайте их коллегам.
  Так готовые файлы собираются сами, на настоящих Mac и Windows.

Про предупреждение безопасности (важно)
---------------------------------------
Приложение пока БЕЗ цифровой подписи. Поэтому при первом запуске система
один раз предупредит «неопознанный разработчик»:
  MAC:     правый клик по MiniFig → «Открыть» → «Открыть».
  WINDOWS: «Подробнее» → «Выполнить в любом случае».
Это единственный лишний шаг у пользователя, и только ОДИН раз.

Убрать это предупреждение полностью можно ТОЛЬКО с сертификатами подписи:
  - Mac: аккаунт Apple Developer (99$/год) + нотаризация.
  - Windows: сертификат Code Signing.
Если нужно — подключу подпись в сборку, когда будут сертификаты.
