Сборка MiniFig через GitHub (бесплатно, без Node и без сборки у себя)
=====================================================================

Итог: GitHub сам соберёт на настоящих Mac и Windows два файла-установщика.
Вы их скачаете и раздадите коллегам. Делается один раз, потом — по кнопке.

ШАГ 1. Аккаунт
  Зайдите на github.com, зарегистрируйтесь (бесплатно), если ещё нет.

ШАГ 2. Создать репозиторий
  Кнопка "+" справа вверху → "New repository".
  - Repository name: minifig-desktop
  - Public (публичный) — тогда сборки бесплатны без лимитов.
    (Если нужен Private — тоже можно, бесплатных минут хватает на десятки сборок.)
  - Нажмите "Create repository".

ШАГ 3. Загрузить файлы проекта
  На странице репозитория: "uploading an existing file"
  (или вкладка Add file → Upload files).
  Перетащите СОДЕРЖИМОЕ этой папки (не саму папку):
     main.js, preload.js, font-scan.js, package.json,
     КАК-СОБРАТЬ.txt, и папку .github целиком.
  ВАЖНО про папку .github:
    Если перетаскиванием она не добавляется (скрытая), сделайте так:
    Add file → Create new file → в поле имени введите:
        .github/workflows/build.yml
    и вставьте туда содержимое файла build.yml из этой папки. Сохраните (Commit).
  Нажмите "Commit changes".

ШАГ 4. Запустить сборку
  Вкладка "Actions" вверху.
  - Если спросит включить workflows — нажмите "I understand... enable".
  - Слева выберите "Сборка MiniFig (Mac + Windows)".
  - Кнопка "Run workflow" справа → ещё раз "Run workflow".
  Через ~5–7 минут напротив запуска появится зелёная галочка.

ШАГ 5. Скачать установщики
  Откройте завершённый запуск (клик по строке с галочкой).
  Внизу в разделе "Artifacts":
     MiniFig-mac  → внутри MiniFig-...dmg
     MiniFig-win  → внутри MiniFig-...exe
  Скачайте, распакуйте zip — это и есть готовые установщики.

ШАГ 6. Раздать коллегам (одна кнопка для них)
  MAC:     .dmg → двойной клик → перетащить MiniFig в «Программы».
           Первый запуск: правый клик по MiniFig → «Открыть» → «Открыть».
  WINDOWS: .exe → двойной клик → ставится сам и запускается.
           Первый запуск: «Подробнее» → «Выполнить в любом случае».
  (Эти предупреждения — потому что без подписи; один раз и навсегда.)

Повторная сборка (после правок)
  Просто снова: Actions → Run workflow. Всё.
